### Ramingo · SOsintOps

Open-source tools for **OSINT** and **cyber threat intelligence**: ready-to-use investigation workstations, curated search toolkits and intelligence aggregators.

#### Investigation workstations
- **[Argos](https://github.com/SOsintOps/Argos)** — turns a clean Ubuntu 24.04 VM into a complete OSINT workstation
- **[Wukong](https://github.com/SOsintOps/Wukong)** — China-focused OSINT workstation for Debian 13
- **[Speculator](https://github.com/SOsintOps/Speculator-Project)** — Debian 13 workstation for cybercrime and OSINT investigations

#### OSINT toolkits
- **[Exploratores](https://github.com/SOsintOps/Exploratores)** — modular browser-based OSINT toolkit · [live demo](https://sosintops.github.io/Exploratores/)
- **[claudii-exploratores](https://github.com/SOsintOps/claudii-exploratores)** — the Exploratores catalog as an agent skill and MCP server

#### Intelligence
- **[elementary-CTI](https://github.com/SOsintOps/elementary-CTI)** — multi-source ransomware threat-intelligence aggregator
- **[Acta Diurna](https://github.com/SOsintOps/acta-diurna)** — OSINT dashboard tracking Italian law-enforcement operations reported by the press
- **[Aethelburg](https://github.com/SOsintOps/Aethelburg-project)** — local analysis of UK Companies House data to spot shell companies
